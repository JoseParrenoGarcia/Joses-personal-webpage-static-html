## Design Principles

### Visual Style
- **Clean and professional**: C-suite appropriate, not startup flashy
- **Minimal and focused**: Avoid clutter, emphasize key CTAs
- **Readable typography**: Large, scannable text with clear hierarchy
- **Whitespace**: Generous spacing for easy reading
- **Mobile-first**: Optimized for mobile viewing (LinkedIn traffic)

### Color Palette
- Professional and trustworthy
- Suggestion: Navy/dark blue + white + accent color (orange or teal)
- Avoid: Overly bright or playful colors

### Typography
- Sans-serif for body text (e.g., Inter, Open Sans, Helvetica)
- Clear hierarchy: H1 > H2 > H3 > Body
- Line height: 1.5-1.6 for readability
- **Header capitalization**: Use sentence case for all section headers (e.g., "Experience that delivers" not "Experience That Delivers")

### Imagery
- Professional headshot on About page
- Optional: Subtle icons or illustrations for service cards
- Avoid: Stock photos, generic business imagery
- Keep it minimal: text and content should dominate

### Layout Preferences
- **Services section**: Display as 2x2 grid (2 columns, 2 rows) for better visual balance
- **Avoid redundancy**: Do not repeat experience/background information across multiple sections

### Navigation
- Fixed header with logo + nav links
- Mobile: Hamburger menu
- Clear active state for current page

### CTAs
- Primary CTA: "Work with me" / "Schedule a consultation" (bold, high contrast)
- Secondary CTA: "Subscribe to newsletter" (subtle, outline style)
- Clear visual hierarchy between CTAs

## User Flows

### Flow 1: C-Suite Executive Seeking Consulting
1. Lands on Homepage (LinkedIn, email signature, search)
2. Reads hero section + credentials
3. Scans services overview
4. Clicks "Learn more" or goes to Services page
5. Reads relevant service description
6. Clicks "Schedule a consultation"
7. Fills out inquiry form on Contact page
8. Receives confirmation + 48-hour response commitment

**Alternative path:**
- Reads featured writing to assess expertise
- Goes to About page for more background
- Then proceeds to Contact

---

### Flow 2: Newsletter Discovery
1. Lands on Homepage or Writing page
2. Sees featured articles and expertise
3. Clicks through to read 1-2 articles (external links)
4. Returns to site
5. Sees newsletter CTA
6. Goes to Newsletter page
7. Reads value proposition and recent issues
8. Enters email and subscribes

**Alternative path:**
- Directly subscribes from homepage without deeper exploration
- Explores Writing page first, then subscribes

---

### Flow 3: Researcher/Evaluator
1. Lands on Homepage
2. Goes to About page to learn background
3. Reads Services page to understand offerings
4. Explores Writing page to assess thought leadership
5. Subscribes to newsletter (low commitment)
6. Later returns to inquire about consulting

## Technical Considerations

### Performance
- Fast load times (< 2 seconds)
- Optimized images
- Minimal JavaScript

### SEO
- Meta descriptions for all pages
- Structured data for articles
- Clear H1/H2/H3 hierarchy
- Alt text for all images

### Analytics
- Track key conversions:
  - Newsletter signups
  - Consulting inquiry form submissions
  - Contact page visits
  - Service page engagement

### Hosting & Domain
- Custom domain (e.g., joseparreno.com)
- SSL certificate (HTTPS)
- Reliable hosting (Vercel, Netlify, or similar)

### Forms
- Contact form submission handling (email notification or CRM integration)
- Newsletter signup integration (e.g., Substack, Mailchimp, ConvertKit)
- Form validation and error handling
- Thank you confirmation after submission

### Mobile Optimization
- Responsive design for all screen sizes
- Touch-friendly buttons and links
- Readable text without zooming
- Fast mobile performance
