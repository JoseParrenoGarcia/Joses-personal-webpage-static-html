# Frontend Design Skillset

## When to Use

Claude must use the `frontend-design` skillset when:
- Implementing new UI components or pages
- Making significant design or layout changes
- Working on visual refinements or aesthetic improvements
- Creating or modifying frontend code that impacts user experience

## How to Use

Invoke the skill at the start of frontend work:
```
/frontend-design
```

## Purpose

The frontend-design skillset provides specialized guidance for creating distinctive, production-grade frontend interfaces with high design quality. It helps avoid generic AI aesthetics and ensures creative, polished implementations that align with this project's Financial Editorial Authority aesthetic.

## When NOT to Use

- Pure content updates without design changes
- Backend or configuration work
- Documentation-only changes
- Minor bug fixes that don't affect design
